Quotations Help Center

Quotations Management

This page allows you to manage all quotations sent to customers, track their status, and make updates as needed.

Key Features

Status Tracking

  • Pending - Quotations awaiting customer response
  • Accepted - Quotations approved by customer
  • Rejected - Quotations declined by customer

Search & Filter

Quickly find quotations by:

  • Quotation number
  • Job title
  • Customer name
  • Status

Quotation Management

  • View Details - See full quotation information
  • Edit Quotations - Update pricing and details
  • Track Status - Monitor customer responses
  • View PDFs - Access generated quotation documents

How to Use

Viewing Quotation Details

  1. Click the button
  2. The full quotation view will open with all details
  3. Review pricing, job details, and customer information
  4. Click Close to return to the list

Editing a Quotation

  1. Click the button
  2. Update the required fields (total cost, deposit, status)
  3. Upload a new quotation PDF if needed
  4. Click Update Quotation to save changes

Managing Quotation PDFs

  1. In edit mode, drag and drop your PDF file
  2. Or click to browse and select the file
  3. The system only accepts PDF files
  4. Remove existing files by clicking the delete icon

Troubleshooting

Can't edit quotation? Ensure you have the proper permissions

PDF not uploading? Verify the file is PDF format and under 5MB

Status not updating? Check all required fields are completed

For further assistance, contact your system administrator.
