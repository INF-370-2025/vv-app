Invoices Help Center

Invoices Management

Track and manage all customer invoices with payment status monitoring and document management.

Key Features

Status Tracking

  • Unpaid - Outstanding payments
  • Paid - Completed transactions

Search & Filter

Quickly locate invoices by:

  • Invoice number (e.g. #INV-001)
  • Job title or description
  • Customer contact details
  • Completion date range

Invoice Actions

  • View Details - See full invoice information
  • Edit Information - Update amounts or details
  • Update Status - Mark as paid when payment received
  • View PDF - Access the invoice document

How to Use

Creating an Invoice

  1. Click
  2. Select the completed job from the list
  3. Verify all items and pricing
  4. Upload the final invoice PDF
  5. Click Submit to generate

Viewing an Invoice

  1. Locate the invoice in the list
  2. Click
  3. Review all details in the popup
  4. Click View PDF to see the document

Marking as Paid

  1. Click
  2. Select "Paid" from the dropdown
  3. Add payment details if required
  4. Click Confirm to update

Managing Documents

  1. Click to see payment proof
  2. Use to save copies
  3. Re-upload documents if needed via Edit

Troubleshooting

Can't view PDF? Ensure the document was uploaded properly

Missing job details? Verify the job card exists and is complete

Edit options disabled? Check your user permissions
