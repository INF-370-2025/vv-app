Users Management Help Center

Users Management System

This page allows you to manage all system users including customers and employees, with tools for viewing, creating, and updating user information.

Key Features

User Categories

  • Customers - Clients who purchase your products/services
  • Employees - Staff members with system access

Search & Filter

Quickly find users by:

  • Name or surname
  • Email address
  • Phone number
  • Company name (for customers)
  • Employee ID (for staff)

User Management

  • View full details - Complete user profiles
  • Create new users - Add customers or employees
  • Update information - Modify user details
  • Employee-specific actions - Payslips, warnings, etc.

How to Use

Viewing User Details

  1. Click the button
  2. The detailed user profile will show all information
  3. For employees: view position, rate, and warnings
  4. For customers: view company details and contact info

Creating New Users

  1. Click the button
  2. Select the appropriate tab (Customers or Employees)
  3. Fill in all required details in the form
  4. Click Create to add the new user

Updating User Information

  1. View the user's details
  2. Click the button
  3. Modify any fields as needed
  4. Click Update to save changes

Managing Employee Documents

  1. View the employee's details
  2. Click
  3. Drag and drop or select the PDF file
  4. Click Upload to complete the process

Employee Warnings

  1. View the employee's details
  2. Click
  3. Enter the reason and select warning type
  4. Click Warn to record the warning

Troubleshooting

Can't create user? Ensure all required fields are completed

User not appearing? Check if filters are applied or try refreshing

Update not saving? Verify you have proper permissions

Payslip upload failed? Ensure file is PDF format and under size limit

For further assistance, contact your system administrator.
