Help Center

Admin Dashboard Help

This dashboard provides real-time business insights and quick access to management tools.

Key Features

Statistics Overview

  • New Requests - Current open job requests
  • Completed Jobs - Weekly completed work orders
  • Total Customers - All customers in system
  • Employees Clocked In - Currently working staff

Click any statistic to view detailed records.

How to Use

Viewing Detailed Data

  1. Click the icon on any statistic card
  2. You'll be taken to the relevant section
  3. Use filters to narrow down results

Generating Reports

  1. Click any report type from the Reports section
  2. Wait for the report to generate
  3. Use the button to export
  4. Filter data using available options

Troubleshooting

Data not updating? Try refreshing the page

Missing reports? Verify your admin permissions

Incorrect numbers? Check date filters

 Timesheet System Help

Timesheet Calendar Overview

This system allows you to manage employee time tracking through generated codes and calendar visualization.

Code Generation

Clock-In/Clock-Out Codes

  • - Creates a unique code for employees to clock in
  • - Creates a unique code for employees to clock out
  • Codes expire after a set time period (shown in countdown)

How to Generate and Share Codes

  1. Click either the Clock-In or Clock-Out code generation button
  2. Wait for the system to generate a unique code
  3. Share the displayed code with employees
  4. Employees must enter this code in their timesheet app
  5. The code will automatically expire after countdown completes

Calendar View

Timesheet Visualization

  • Interactive calendar displays all employee timesheet entries
  • View daily, weekly, or monthly time tracking data
  • Click on events to see detailed time entry information

Using the Calendar

  1. Use the calendar header navigation to change views
  2. Click on any event to see details
  3. Different colors indicate different statuses (clock-in, clock-out, etc.)

Troubleshooting

Code not working? Verify the code hasn't expired and was entered correctly

Calendar not loading? Check your internet connection and refresh the page

Missing time entries? Ensure employees properly submitted their codes

 Customer Dashboard Help

Welcome to Your Customer Dashboard

This is your central hub for managing all job-related documents and requests.

Dashboard Features

Job Requests

  • Submit new service requests
  • Track status of existing requests
  • View request history

Quotations

  • View and download price quotes
  • Check quotation status
  • Approve or request changes

Invoices

  • View and pay outstanding invoices
  • Download payment receipts
  • Access invoice history

Delivery Notes

  • View completed job documentation
  • Download delivery confirmations
  • Access historical records

How to Navigate

Accessing Sections

  1. Click any card to enter that section
  2. Use the main menu for additional options
  3. Return to dashboard using the home icon

Finding Documents

  1. Each section has search functionality
  2. Filter by date range or status
  3. Use the "View" buttons to open documents

Common Questions

Can't find a document? Check your filters or refresh the page

Document won't open? Ensure you have PDF reader software

Missing features? Some options may require approval first
